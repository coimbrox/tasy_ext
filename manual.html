Manual — Tasy DevTools

Como funciona

A extensão ativa suas funcionalidades automaticamente em qualquer aba cujo domínio contenha "tasy" no hostname (produção, homologação, dev). Não é preciso configurar nada — basta abrir o popup (clicando no ícone da extensão) e marcar as opções desejadas.

Dicionário de dados

Enquanto você navega pelo TASY com os overlays de metadados ligados (abaixo), a extensão vai aprendendo sozinha os nomes técnicos de campos, colunas de grid e painéis que você encontra pelo caminho, junto com o rótulo (label) que aparece na tela.

No campo de busca no topo do popup, digite parte do nome técnico (ex.: CD_PESSOA_FISICA), do rótulo (ex.: "paciente") ou da tabela, e veja tudo que já foi visto. Clique num resultado para copiar o nome técnico.

Quanto mais você usa o TASY com os overlays ativos, mais completo fica o dicionário — ele é só seu, guardado localmente no navegador.

Cores por ambiente

Cadastre regras como "domínio contém hml → laranja, rótulo Homologação" no popup. Quando o hostname da aba bater com uma regra, a extensão mostra uma borda colorida ao redor de toda a tela e uma etiqueta arrastável com o rótulo — assim fica óbvio de relance se você está em produção, homologação, desenvolvimento ou qualquer outro ambiente que você configure. Funciona só com o hostname da própria aba, sem depender de cookie ou servidor.

Mostrar o estabelecimento logado

A caixa "Mostrar o estabelecimento logado na etiqueta" acrescenta à etiqueta o estabelecimento em que você está (matriz/filial) — que normalmente só aparece pequeno no rodapé. Fica algo como Homologação · Filial 2 · nó 1114. É especialmente útil em instalações multi-estabelecimento, para não gravar/alterar coisa no lugar errado. Se não houver regra de cor para o domínio, a extensão mostra uma etiqueta cinza só com o estabelecimento. O nome é lido do próprio TASY (rodapé/sessão), nada é enviado para fora.

Metadados TASY

Cada opção abaixo liga/desliga um "overlay" — uma informação extra que a extensão desenha por cima da tela do TASY. A caixa "Ativar todos" no topo liga ou desliga as sete de uma vez (fica em traço quando só algumas estão ligadas).

Detalhes de campo

Mostra, acima de cada campo de formulário, o nome técnico da coluna (ex.: CD_RELATORIO, DS_TITULO). Clique num badge para copiar o valor.

Detalhes de grid

Mostra o nome técnico da coluna no cabeçalho de cada grid (SlickGrid).

Detalhes de painel

Mostra código/tipo, view e tabela do painel/tela atual (ex.: WDBPANEL 1038025, VIEW 96218, RELATORIO), útil para identificar rapidamente a tabela por trás de uma tela. Em telas com linhas curtas e empilhadas (ex.: as categorias da CPOE), o badge fica fixo no canto inferior direito da linha em vez de cobrir o título nativo.

Recentes (tela inicial)

Na tela inicial do TASY, mostra um painel lateral com as últimas telas abertas, para acesso rápido — clique para abrir, "×" para remover da lista.

Idioma do usuário no rodapé

Mostra o idioma da sessão atual ao lado da data no rodapé da tela.

Modo inspeção

Exibe um botão "Inspecionar" fixo na tela. Clique nele, depois clique em qualquer elemento da página. Abre uma janela com dois blocos:

  • Contexto da função (no topo): a função aberta, o painel/view/tabela daquele componente, os parâmetros encontrados no escopo (qualquer objeto com "param" no nome, listado chave → valor) e as regras detectadas ali (cor de fundo aplicada, elemento oculto por condição, chaves de regra no escopo). Serve para responder "quais parâmetros e regras estão agindo nesta tela".
  • Escopo AngularJS completo (abaixo): o objeto de escopo inteiro, para investigar de onde vem um dado que não tem badge.

As consultas que carregam essas regras e parâmetros (SQL_SQL_GET_COLOR_RULES, SQL_SCRIPT_PARAMETERS, OBTER_PARAMETROS_USUARIO…) você abre no Explorador do app server.

Waterfall de rede

Mostra um painel fixo (arrastável, no canto inferior direito) com as últimas ~15 requisições reais que a página fez, em forma de linha do tempo: método + endereço, uma barra proporcional à duração e o tempo em ms. As lentas ficam em laranja, as que deram erro em vermelho. Clique numa linha para copiar o endereço. Use para achar "qual chamada está segurando a tela"; para ver o lado servidor, abra o arquivo correspondente no Explorador do app server.

Layout visual (relatórios) EXPERIMENTAL

Quando a grade atual tem as colunas Esquerda/Topo/Tamanho/Altura (editor de bandas/campos de relatório do TASY), mostra um botão "📐 Layout visual" que abre um canvas mostrando os campos já cadastrados nas posições reais. Arraste um novo campo até a posição desejada e clique em "Copiar" para levar os quatro números prontos para colar na grade. Tanto o botão quanto o canvas podem ser arrastados para qualquer lugar da tela. É somente leitura — nunca escreve na grade do TASY.

Registrar Processo

Pensado para documentar um processo passo a passo — por exemplo, para anexar num chamado aberto com a Philips.

Iniciar registro: zera o log e começa a gravar, em ordem cronológica, cada tela aberta, clique em botões/links e valor preenchido em campos (exceto senhas). Internamente também mede a latência de rede para detectar oscilação, mas isso não aparece no texto final.

Execute normalmente o processo que quer documentar.

Parar registro: encerra a gravação e automaticamente:

  • Tira um print final da tela exatamente como ela está no momento em que você para (o "resultado" do processo, que nenhum clique cobre) e adiciona como último passo — "🏁 Fim do registro";
  • Copia para a área de transferência um resumo em texto do passo a passo;
  • Baixa um arquivo .html com o mesmo passo a passo, incluindo um print da tela em cada passo — pronto para anexar num chamado de suporte.
[14:32:10] 🖥️ Tela aberta: Cadastro de Usuários [14:32:12] ⌨️ Preencheu "Código": 12345 [14:32:15] 🖱️ Clicou em: Salvar [14:32:18] 🏁 Fim do registro — tela ao parar a captura
Atenção: como o registro guarda os valores digitados nos campos, revise o texto/arquivo antes de compartilhar caso o processo envolva dados sensíveis (ex.: dados de paciente).

Capturar erros

Para que serve

Às vezes você faz algo no TASY e aparece uma tela vermelha: "Houve um erro na execução da aplicação", com um texto técnico curto como "Nome de coluna inválido". Essa tela não diz o que deu errado, onde, nem por quê. Com esta opção ligada, a extensão pega esse erro e monta uma explicação em português, já com o passo a passo de como investigar — pronta para colar num chamado.

Como ligar (uma vez só)

  1. Abra o popup da extensão (ícone na barra do Chrome).
  2. Na seção Capturar erros, marque a caixa "Capturar e explicar erros do TASY".
  3. Clique em Testar acesso. Se aparecer "Acesso OK", está pronto. Se aparecer "Precisa de login", abra o endereço do app server uma vez no navegador e clique em "Testar acesso" de novo.

Pronto — pode fechar o popup e trabalhar normalmente. Ele continua ligado nas próximas vezes que abrir o navegador.

O que acontece quando dá erro

Assim que a tela vermelha aparece, sozinha e em segundo plano, a extensão:

  • abre o arquivo de erro no console do app server (aquele endereço com a lista de arquivos wheb_arquivo.jsp) usando o seu login que já está ativo no navegador — a senha do app server nunca é digitada nem guardada;
  • lê a mensagem real do servidor, qual processo estava rodando (ex.: "exportar perfil"), os parâmetros (ex.: qual perfil) e em que ponto do código quebrou;
  • no caso do "Nome de coluna inválido" (o Oracle não diz qual coluna), busca as consultas SQL que rodaram naquele processo, com os valores reais e o nome das tabelas — para você comparar e achar a coluna;
  • mostra um painel na tela com tudo organizado e um botão Copiar relatório.

Como fica o relatório

== O QUE ACONTECEU == Uma consulta SQL tentou ler uma coluna que não existe... == EM QUAL PROCESSO == ação exportarPerfil — falhou em CorSis_FOAction.montaAtributosItensPront == SOBRE O QUÊ == CD_PERFIL=2150, DS_PERFIL=UUE - Triagem == O QUE VERIFICAR == - Tabelas envolvidas: PERFIL_ITEM_PRONT_PASTA — comparar as colunas reais com o SELECT abaixo; a que faltar é a culpada. - Confirmar scripts de atualização aplicados (versão 5.04.1845.136). == CONSULTAS DO PROCESSO == • SQL_GERAR_TAB_PRONT_QUERY_AUX [tabelas: PERFIL_ITEM_PRONT_PASTA] SELECT distinct dt_atualizacao, nm_usuario, ... FROM PERFIL_ITEM_PRONT_PASTA a WHERE nr_seq_item_perfil = '1011'

"Este erro já aconteceu"

Se o mesmo erro (mesmo tipo, mesma tela, mesmo processo e mesmo parâmetro-chave, ex.: o mesmo perfil) já tiver acontecido hoje, o relatório e o painel avisam: "⚠ Este erro já aconteceu: 3× hoje (1ª vez às 09:40)". Na lista do popup, o item mostra · ×3 hoje. Serve para saber de cara se é um problema recorrente ou pontual.

Ver de novo depois

Os últimos erros ficam listados no popup. Clique num item para copiar só ele, ou use Baixar relatório para um arquivo .html com todos.

Endereço do app server

O campo "URL do app server" normalmente fica vazio — a extensão usa o mesmo endereço do TASY automaticamente. Só preencha se, na sua empresa, o app server ficar em outro endereço.

O relatório pode conter números de registros ou de pacientes ligados à operação que falhou (números longos são trocados por •). Sempre leia o relatório antes de anexar num chamado.

Servidor / nó do app server

Para que serve

Quando a empresa tem vários servidores de aplicação (um "cluster"), a sua sessão fica presa a um deles. Às vezes um erro só acontece em um servidor específico — e saber em qual você está economiza tempo no diagnóstico.

Onde aparece

A extensão descobre isso sozinha (do cookie JSESSIONID, cujo valor no Wheb é algo como tasy-tasyappserver-…_1114~…) e mostra o número do servidor — no exemplo, 1114 — em três lugares:

  • no popup, logo abaixo da lista de erros: "Servidor atual: nó 1114";
  • no relatório de erro, na linha "Servidor (nó)";
  • na etiqueta de Cores por ambiente, se você tiver uma regra ativa: HML · nó 1114.

Só o número do nó é lido — a extensão não lê nem guarda o restante da sua sessão.

Gerar chamado

Para que serve

Escrever um chamado completo dá trabalho: ambiente, versão, servidor, passos, o erro... Este botão junta tudo isso automaticamente, a partir do que a extensão já registrou.

Como usar

  1. Se quiser incluir o passo a passo, grave-o antes com o Registrar Processo.
  2. Na seção Gerar chamado, escreva numa linha o que deveria acontecer e na outra o que aconteceu.
  3. Clique em Gerar texto. O texto aparece na caixa, já com ambiente, nó do servidor, versão, função/tela, os passos e o último erro capturado.
  4. Ajuste o que quiser direto na caixa e clique em Copiar.

Como fica o texto

AMBIENTE: tasy.suaempresa.com.br | nó do app server: 1114 VERSÃO TASY: 5.04.1845.136 FUNÇÃO/TELA: [2150] UUE - Triagem USUÁRIO: gabriel.oliveir PASSOS PARA REPRODUZIR: 1. Abriu Cadastro de Perfil 2. Clicou em Exportar ESPERADO: o perfil deveria exportar sem erro OBTIDO: erro "Nome de coluna inválido" --- ERRO CAPTURADO --- (o relatório completo da captura de erros entra aqui)
O texto inclui os passos e o erro capturado — revise antes de enviar caso envolva dados sensíveis.

Explorador do app server

Para que serve

O app server guarda, para cada usuário, um "rastro" de tudo que rodou no servidor: cada consulta SQL, cada procedure, cada erro. Esse rastro fica num console de arquivos difícil de navegar. Esta seção traz uma lista limpa disso dentro do popup — útil para ver a consulta exata que uma tela disparou, quanto tempo levou, ou o erro que acabou de acontecer.

Como usar

  1. Com o TASY aberto e logado na aba ativa, abra o popup e vá em Explorador do app server.
  2. Clique em Atualizar lista. Aparecem os arquivos mais recentes do seu usuário (SQL_…, PROCEDURE_…, ERRO_…), com o tempo de execução e a hora.
  3. Use o campo Filtrar por nome para achar rápido (ex.: digite PERFIL, GERAR ou ERRO).
  4. Clique num item para ver o conteúdo na caixa de baixo — a consulta SQL já com os valores reais, ou o texto do erro. Copiar conteúdo leva tudo para a área de transferência.
O conteúdo pode conter valores reais (inclusive de pacientes). Revise antes de compartilhar.

Utilitários

Limpar recentes

Esvazia a lista de "Recentes" da tela inicial.

Recarregar estilos

Força o navegador a buscar de novo os arquivos CSS da página TASY, sem precisar recarregar a página inteira — útil quando alguém está ajustando o visual de uma tela ao vivo.

A extensão não envia nenhum dado para servidores externos — tudo fica local no seu navegador. Veja a política de privacidade completa para detalhes.
